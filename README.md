# FixMyForm

FixMyForm is a modern, AI-powered biomechanics analysis application designed to help users perfect their lifting technique, prevent injury, and maximize their strength gains through actionable, intelligent feedback.

## Features

- **Form Analysis**: Upload lifting footage to receive instant, personalized coaching cues regarding joint alignment and execution.
- **Diet & Nutrition**: Customized nutritional architecture optimized to fuel workouts, maximize recovery, and accelerate results.
- **Science-Based Programs**: Periodized, evidence-based hypertrophy systems for consistent strength progression.
- **Modern UI Aesthetic**: A highly refined, fast, and minimalist user interface built with modern web technologies that emulates a high-end photography gallery.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4, custom CSS modules
- **Language**: TypeScript
- **Machine Learning**: MediaPipe Vision (Client-side native pose estimation)

## Getting Started

First, install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3002](http://localhost:3002) in your browser to see the result.

## Project Structure

- `src/app`: Next.js App Router pages and global configurations.
- `src/components`: Reusable UI components (Hero, Features, Header, Footer, ExerciseSelector, etc).
- `src/lib`: Core application logic, exercise definitions, angle calculators, and AI coaching integration.
